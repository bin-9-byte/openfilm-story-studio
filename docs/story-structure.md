# 幕／序列与稳定场号

2026-11-22。浏览器本地版与本机版共用原生编辑操作，分组不替代剪辑轨道。

## 使用入口

1. 在「剧本创作」或「场次与分镜」编辑区，展开「幕／序列与场号」。默认折叠，不另加一层工作区导航。
2. 选择「幕」或「序列」，填写名称并新增。序列可归入一幕，也可独立存在；幕数不限，不强制三幕结构。
3. 在左侧目录或时间轴选中节拍／场次，再用「所选内容分组」归入目标幕或序列。支持多个所选对象一起归组。选择「未分组」仅移除归属，不删除内容。
4. 展开某个分组，可改名、上移／下移、调整序列所属幕或删除分组。删除幕会让其子序列变成独立序列；删除分组会移除直接成员的归属，保留所有正文、场次、分镜和时间位置。
5. 左侧目录按结构展示，可折叠。剧本节拍仍注明原故事线；全片总览可筛选某幕及其子序列。场内分镜显示稳定场号及结构路径。

分组的排序只影响结构目录和场次总览；时间轴、剧本串读的呈现时间和既有剪辑交互继续保留。每个呈现片段当前归属一个幕或序列；同一共享正文的不同呈现片段可分别归入不同分组。

## 场号规则

- 旧工程未固定场号时显示「未固定」。点击「固定现有场号」或首次新增结构分组，按现有场次时间顺序分配 S001、S002 等；这是一个可撤销的操作，不在打开页面时自动改写工程。
- 新建场次会确保场号体系存在并分配新号。之后场次无论移动到哪里，场号都跟随场次身份，不按场序重排。
- 场次选中时，可在面板内修改「稳定场号」，例如 12A。全工程唯一，大小写视为同号；允许数字、字母、中文和 `. _ -`，最多 32 字符。
- 删除场次仍保留其场号登记和计数；新增场次不占用这个旧号。撤销删除恢复同一身份和场号。
- 分割场次时左半保留原号，右半分配新号并继承分组；一次撤销恢复完整场次、分组与编号状态。复制／插入获得新身份的场次也会分配新号。
- 撤销整个“创建场次”操作会同时恢复操作前的编号状态；重做会重现相同场次与场号。
- 分镜镜号仍为场内排序；本轮稳定的是场号，不把镜头序号冒充稳定镜号。

## 保存与兼容

工程级可选 `storyStructure` 包含分组、以片段 ID 为键的成员关系、以场次 ID 为键的场号登记以及下一个默认号。它与独立正文 `screenplay` 分开，并编码为 `film.html` 中不执行的 metadata，原生轨道与 clip 格式保持不变。

所有修改走现有编辑事务与会话撤销。原生场次分割／插入结束后统一分配缺失的场号；撤销同时恢复隐式产生的编号与分组变更。正文来源和场内分镜不因分组更改而移动或改写。

IndexedDB 自动保存、离线应用、完整工程 `.openfilm.json` 备份和完整工程文件夹导入均携带该 metadata。旧工程不批量覆盖正文或调整场次位置。刷新／重启不保证恢复原编辑器的会话撤销栈。

## 验收

- 229 项相关单元回归通过，包括分割两种原生操作形式的自动编号、归组和整体撤销、重复／保留场号与 HTML 往返。
- 原片样例实测两幕、序列与节拍／场次归组、改名、改所属幕、排序、删除与一次撤销；时间与引用保持。
- 真实场次拖拽、右端修边缩短与撤销不改变场号；删除／撤销／重做后旧号仍保留，新场继续新号。
- 总览按幕筛选包含子序列；进入现有场内分镜保持场号与分组上下文。
- 断网刷新、完整工程导出／导入、关闭浏览器后离线重开恢复结构与分镜。
- 既有跨场段落、多线共享、空场次／空镜头、工程离线恢复流程回归通过。

测试使用用户本机原片验证工程；原片素材不随公开仓库发布。
