# 工作台页面设计

## 问题审计

- 顶部：创作阶段、全片总览、内容类型与影像模式混成两排同权重按钮。
- 正文：统一灰色输入框使名称、正文和备注缺少阅读层级，过大边距压缩可编辑空间。
- 上下文：缺少对象目录，选中了哪条线、哪个场次／镜头不够直观。
- 右侧：画布、尺寸与帧率等影像属性占据写作页面，挤压正文。
- 操作：新增入口散落在底部，核心动作与辅助动作同样强调。
- 状态：编辑中的草稿也显示「已保存」，缺少待保存状态。
- 验收：已有功能说明分散在开发记录里，页面内没有明确的操作路径与预期结果。

## 设计方向

产品：帮助短片创作者组织剧本、划分场次并设计镜头。
气质：安静、明确、可持续阅读。
世界：剧本纸页与剪辑台，沿用现有深色中性表面和青色强调。
内容重点：正文的阅读节奏，以及原片分镜图。
统一标记：对象类型、所属剧本线／场次、时间范围。

## 页面结构

一层导航：剧本创作／场次与分镜／全片总览。
上下文工具条：当前对象与时间、核心动作、内容／影像模式。
内容区：左侧对象目录，右侧正文或分镜；备注收在次要区域。
底部：继续使用原生时间轴。
影像属性面板：内容模式默认收起，切换影像或手动打开时可使用。
操作与验收：通过页面内的说明面板走通串读定位、分镜检查、保存与撤销。

本轮不增加声音功能，见 TODO.md。

设计整理参考 unslop by Damir Sokolovsky (@heydamir), CC BY 4.0：https://heydamir.design/unslop

## 已落实与验证

统一单层导航与上下文工具条；内容模式收起影像属性；新增左侧目录；正文与备注分级；新增按钮固定在工具条；来源、时长、分镜原有功能保留。修正缺失的边框色变量映射，使输入边界与分组线可见。

右上角「操作与验收」包含三步操作和预期结果。窗口1351×928下检查正文、分镜及验收面板，原片样例实测目录定位、草稿与保存提示、新增节拍及推后撤销、新增镜头撤销、影像属性切换、跨场定位及返回正文。测试追加内容均已撤销，样例数据保持不变。

95项单元与剪辑／历史测试通过，前后端类型检查和构建通过。页面改造不改变工程格式。

## 场内镜头往返衔接

原先场次与分镜是两个工程路由，切换时卸载页面并显示整页品牌加载界面。现在先读取目标工程，将这次读取交接给工程加载器；浏览器保留旧画面，等目标正文、轨道和可见图片准备好后进行140毫秒淡入。读取交接只消费一次，不缓存旧工程数据。不支持 View Transition 的浏览器仍采用正常路由切换；减少动态效果设置下不播放淡入动画。

进入按钮、轨道双击、内容区返回和时间轴返回使用相同逻辑。离开前等待保存，返回时恢复选中场次、原播放位置和正文滚动位置，再次进入恢复原镜头。恢复位置允许播放头在选中场次之外；普通总览定位仍跳到目标内容。导航本身不增加撤销步骤。

回归命令（Chrome 可用 CHROME_PATH 指定，服务地址可用 STUDIO_URL 指定）：

```sh
node scripts/check-scene-navigation.mjs 1heKjxuHgUTF '夜街 · 合照与离别（验证段）' '眼部特写'
```
